# Универсальная йога · Непал 2027

Готовая локальная версия сайта курса Андрея Лаппа. Все пять частей, даты 2027 года, полные программы теории и практики, условия участия, сертификация, проживание и контакты.

Хостинг: GitHub Pages.

Репозиторий: https://github.com/utromaya-code/universal-yoga-nepal-2027

Адрес GitHub Pages: https://utromaya-code.github.io/universal-yoga-nepal-2027/

Собственный домен: universal-yoga.pro. Для активации нужно направить DNS домена на GitHub Pages.

## Открыть сайт

Откройте `dist/index.html` в браузере. Фотографии, шрифты и функции сайта работают локально. Интернет нужен для формы регистрации и внешних ссылок.

Для локального предпросмотра с адресом можно запустить из этой папки:

```sh
python3 -m http.server 4173 --directory dist
```

Затем открыть `http://localhost:4173/`.

## Что включено

- Полные программы всех пяти частей. Материалы частей 3 и 5 обновлены по предоставленному тексту.
- Мобильное меню и доступные с клавиатуры вкладки программ.
- Раскрывающиеся списки теории и ежедневной практики.
- Прежние цены и переключение первого/повторного прохождения, с экзаменом/без экзамена.
- Фотографии пользователя, логотип UYTT Nepal и галерея с увеличением.
- Ссылка на новую форму Яндекса во всех кнопках регистрации.
- Локальные шрифты с лицензиями. Аналитики и сторонних скриптов нет.

## Файлы

- `dist/index.html` — вся страница и полные программы.
- `dist/styles.css` — оформление и мобильные стили.
- `dist/site.js` — меню, вкладки, стоимость и галерея.
- `dist/assets/` — фотографии и шрифты.
- `content/programs.json` — удобная редакционная копия программ. Изменения в ней нужно переносить в HTML: сайт не загружает JSON во время работы.
- `.github/workflows/deploy-pages.yml` — автоматическая публикация папки `dist/` на GitHub Pages.

## Публикация на GitHub Pages

Сайт не требует сборки и серверной части. Папка `dist/` содержит готовую версию для размещения. После изменений в `dist/` и отправки в ветку `main` GitHub Actions автоматически публикует обновление. Внешний доступ к исходному Taplink для работы сайта не нужен.
